**Results Display System**
A simple Python-based Results Display System that allows users to manage student information and marks through a basic menu-driven program.

**Features**
Add student
Add marks
Display marks
Update student information
Exit the program

**Technologies Used**
Python

**Concepts Used**
Variables
Lists
Functions
Loops
Conditional statements
User input and output

**How to Run**
Make sure Python is installed on your computer.
Download or clone this repository.
Open the project folder in your code editor or terminal.
Run the Python file:

**python results_display_system.py**
Select an option from the menu and follow the instructions.

**Purpose**
This project was created to practice Python programming concepts and build a simple student results management system.
